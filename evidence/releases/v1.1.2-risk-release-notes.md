# PackBreaker v1.1.2

本版本将 PTerClub、Audiences、SpringSunday、HDDolby、U2、不可躺（TANGPT）与 CarPT 的代码适配状态开放为 `SUPPORTED`，并新增站点管理与 CookieCloud 双卡切换。

## 重要风险提示：七站完整真实 E2E 尚未验收

**正式逐站真实 PackBreaker 完整拆包 E2E 收据仍是 0/7，不得解释为已全部实测通过。** 经用户明确批准，本次版本在接受这一缺口与实际运行兼容性风险的前提下发布。代码适配已开放，完整链路是否成功还取决于站点凭证/网络、合法 Torrent、内容校验、执行计划、文件系统权限和下载器。

本次决定有独立审计记录：[v1.1.2 显式风险接受及授权](https://github.com/YYxiaoma/PackBreaker/issues/5#issuecomment-6164915759)。网络、Tracker 及异常恢复的现场验证安排至后续版本：[Issue #33](https://github.com/YYxiaoma/PackBreaker/issues/33)。

已有实时文件验证、权限检查、下载器及 Journal 安全门禁继续生效，旧 CarPT 只读执行不会被解冻。

## 部署

支持 `linux/amd64` 与 `linux/arm64`，镜像同步发布至 GHCR 和 Docker Hub。部署及升级请见 [README](https://github.com/YYxiaoma/PackBreaker#readme)。
