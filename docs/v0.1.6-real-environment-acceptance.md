# v0.1.6 真实环境验收记录

本文记录 v0.1.6 在 2026-09-18 正式发布前后已完成的真实环境只读验收、正式 Release 证据，以及仍依赖外部条件的未完成项。本文不保存 Cookie、API Key、密码、代理凭证、用户名、UID、真实下载目录、Tracker 或原始 torrent。

## 1. 验收安全边界

本轮真实验收严格限制为只读远端操作：

- 不执行拆包任务、站点搜索、Torrent 下载或辅种写链；
- 不执行下载器 add/start/stop/recheck/remove；
- 不创建、删除、移动、链接或修改真实媒体文件；
- 不在真实 v0.1.5 数据库上执行迁移；
- 使用 SQLite backup API 生成一致性数据库副本，仅在 /tmp 副本上迁移到 v0.1.6；
- SecretStore 主密钥只复制到临时验收目录，不输出或提交明文凭证；
- 远端只调用下载器只读版本/统计 RPC，以及站点登录状态/用户详情只读接口。

## 2. v0.1.5 → v0.1.6 真实配置副本迁移

真实运行库当前 Alembic revision 为 0024_task_center_v015。使用 SQLite backup API 生成一致性副本后，仅对副本执行 upgrade head，最终 revision 为 0026_ai_agent_v016。

迁移后确认以下非敏感配置保持一致：

- 任务定义与任务来源完全一致；
- 下载器名称、类型、Base URL、Secret 引用、路径映射、启用状态等核心配置一致；
- 站点名称、类型、Base URL、凭证类型、Secret 引用与启用状态一致；
- 管理员既有密码哈希保持一致，不被 bootstrap 环境变量覆盖；
- 既有管理员用户名字段按兼容迁移规则补为 `admin`，`must_change_password` 保持关闭；
- 既有 Secret 行的 id/kind/ciphertext/key version 保持一致；
- 5 条既有 Secret 的 ciphertext 指纹逐条保持一致；
- 两个既有下载器、三个既有站点、13 个任务定义均保留。

自动化迁移矩阵另已覆盖所有历史 revision 到 0026_ai_agent_v016；本节补充的是当前真实 v0.1.5 配置的现场副本证据。

## 3. 下载器真实只读验收

### qBittorrent

- 实际版本：qBittorrent v5.2.3；
- WebAPI：2.15.1；
- 认证与 v0.1.6 连接探针成功；
- 运行指标能够读取上传/下载速度、全部 Torrent 内容总大小、剩余空间和任务总数；
- “当前文件总大小”真实按该下载器全部 Torrent 任务内容总大小聚合，不是当前活动任务大小。
- 真实列表共 28 个 Torrent；28/28 的 save path 均能通过现有路径映射落到容器目录，
  28/28 映射目录均存在且可读，未发现未映射路径。

### Transmission

- 实际版本：Transmission 4.1.3；
- RPC semver：6.0.1；
- JSON-RPC 2.0 snake_case 连接探针成功；
- 运行指标能够读取上传/下载速度、全部 Torrent 内容总大小、活动任务数和任务总数；
- 当前实例对默认下载目录执行 free_space 返回 JSON-RPC system error，底层错误为 “No such file or directory”；兼容字段 download_dir_free_space 同时返回 -1。
- 真实列表共 3220 个 Torrent；3220/3220 的 save path 均能通过现有路径映射落到容器目录，
  3220/3220 映射目录均存在且可读，未发现未映射路径。

因此当前实例的 free_space_bytes = null 是“服务端无法查询”的真实未知状态，前端显示 “—”；不得伪造为 0，也不视为 v0.1.6 解析失败。Transmission 官方 4.1 RPC 契约中的 free_space/size_bytes 路径仍由自动化契约测试覆盖。

## 4. PT 站点真实只读验收

### M-Team

- 现有 API Key 能够通过可信 Registry 固定 API origin 调用用户 profile；
- 真实响应中的身份、等级、上传量、下载量、分享率和 Bonus 均可解析为统一
  `SiteUserProfile`；
- 本轮真实响应确认统计位于 `memberCount`，分享率字段为 `shareRate`。验收据此发现并修复
  v0.1.6 适配器遗漏：`memberCount` 已加入 profile source，`shareRate` 已加入 ratio alias，
  并增加与当前真实结构同形的合成回归测试；
- 本轮未执行搜索、详情、Torrent 获取等额外请求。

### HHClub

- 现有 Cookie 能够通过 https://hhanclub.net 完成 NexusPHP 登录态与用户详情读取；
- v0.1.6 SiteUserProfile 能够解析真实返回；
- 本轮未执行搜索、详情、Torrent 获取等额外请求。

### HDTime

- 当前验收环境访问 https://hdtime.org/ 时，Cloudflare 返回 HTTP 500；
- 使用现有 Cookie 的 v0.1.6 用户详情读取返回 SITE_UNAVAILABLE，而不是 SITE_AUTH_FAILED；
- 额外使用浏览器 User-Agent + 浏览器请求头仿真后仍返回 SITE_UNAVAILABLE；
- 同一环境访问 HHClub 可正常得到 HTTP 响应，因此当前证据更符合 HDTime 站点/链路暂时不可用，而不是 v0.1.6 Cookie、UA 或浏览器仿真回归。

在 HDTime 恢复可访问前，不把本轮 HDTime 状态记为 v0.1.6 真实通过，也不通过修改 Cookie、放宽 TLS/重定向/同源规则或猜测镜像域名来绕过。
