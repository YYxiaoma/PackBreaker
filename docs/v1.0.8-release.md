## 2. 本版本核心变化

1. 目录任务和影片去重不再依赖单一 `/data` 根；`/downloads`、`/downloads2`、`/mnt/media` 等显式挂载目录可直接以容器绝对路径使用。
2. `/` 仅作为路径命名空间根，任务文件副作用仍限定在运行时识别出的显式授权挂载根；`/config`、系统目录、`..`、NUL 和符号链接越界继续失败关闭。
3. 历史相对路径继续按 `PACKBREAKER_DATA_DIR`（默认 `/data`）解释，不迁移、不重写旧任务。
4. 官方推荐直接以最终 `PUID:PGID` 非 root 身份运行，不再要求先 `user: "0:0"` 再降权；旧 root 入口继续兼容。
5. docker.sock 通过 supplementary group / Compose `group_add` 授权，PackBreaker 不修改宿主 socket 权限。
6. 启动前增加 `/config` 及 logs/backups/updater/数据库/密钥等关键路径权限预检，权限不匹配时给出明确的宿主修复提示。
7. updater replacement plan 保留容器 User、GroupAdd、docker.sock 和任意媒体 bind，覆盖正式升级、失败自动回滚及 ARM64 场景。
