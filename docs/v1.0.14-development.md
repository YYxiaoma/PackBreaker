# PackBreaker v1.0.14 研发说明

## 1. 版本目标

v1.0.14 聚焦任务中心新增任务体验、监控下载器任务过滤、执行详情可读性，以及站点候选结果的相关性控制。

本版本范围：

1. “新增任务”任务类型选择改为卡片样式。
2. 监控拆包的执行时间移动到扫描站点下方独占一行，避免扫描站点控件被挤压。
3. 监控拆包来源为下载器时，支持按任务名称、分类、标签二次过滤。
4. 删除新增拆包任务中的两段旧 v0.1.5 安全链提示。
5. 来源为下载器时隐藏文件过滤配置。
6. 任务详情配置页将来源快照改为链接打开独立弹窗。
7. 补齐执行状态、阶段、验证等级、操作状态等中文映射。
8. 执行对象保持单行省略并支持 Tooltip，固定审批列使用实体背景。
9. 审核候选改为下拉选择，并修复站点搜索噪声候选进入审核列表的问题。

## 2. 新增任务交互

### 2.1 任务类型卡片

统一新增任务 Dialog 使用三张可点击卡片：

- 手动拆包；
- 监控拆包；
- 影片去重。

卡片具有明确选中态，仍保持“无论当前任务中心选中哪个任务卡片，都能创建任意任务类型”的行为。

### 2.2 监控任务执行时间布局

监控拆包的“执行时间”不再参与基本信息双列网格布局。

新布局：

1. 任务名称 / 任务类型；
2. 扫描站点；
3. 执行时间独占下一行。

浏览器 E2E 会读取实际 DOM 布局坐标，要求执行时间控件位于扫描站点控件下方。

## 3. 下载器监控过滤

### 3.1 配置模型

下载器监控过滤保存在既有 source_config.monitor_filter 中，不新增数据库迁移。

字段：

- name_contains：任务名称包含关键字，不区分大小写；
- categories：允许多个分类，按精确值匹配；
- tags：允许多个标签，命中任意一个即可。

不同过滤维度之间采用 AND 关系；同一标签列表内部采用 OR 关系。

未配置 monitor_filter 的旧监控任务保持原行为，继续扫描全部符合既有安全条件的下载器任务。

### 3.2 扫描顺序

监控下载器任务扫描顺序调整为：

1. 读取下载器 torrent 列表；
2. 应用任务名称 / 分类 / 标签过滤；
3. 检查是否下载完成；
4. 解析路径映射；
5. 进入媒体文件识别与既有安全执行链。

过滤发生在文件系统扫描之前，避免无关下载器任务进入后续媒体分析。

### 3.3 文件过滤显隐

“文件过滤”只在目录来源时展示。

下载器来源已经通过 torrent 元数据过滤确定捕获范围，前端不再展示容易造成概念混淆的文件过滤配置。底层视频文件识别与安全执行限制仍然保留。

## 4. 任务详情与执行详情

### 4.1 来源快照

任务详情“配置”页不再直接展开 source_config JSON。

改为：

- 展示“来源快照配置”链接；
- 点击后打开独立 Dialog；
- Dialog 中显示完整冻结配置。

### 4.2 状态与阶段中文化

补充任务执行与兼容历史数据可能出现的状态/阶段映射，包括：

- 等待处理；
- 搜索候选；
- 匹配候选；
- 执行前检查；
- 等待人工确认；
- 创建链接；
- 添加下载器任务；
- 客户端下载校验；
- 做种中；
- 暂停 / 重试；
- 取消 / 回滚；
- 已取消。

任务审核、执行动作提示、旧任务中心、候选分析页和操作对账页同样使用中文展示，稳定技术码仍保留用于排障。

### 4.3 执行对象表格

执行对象的名称、来源与 source object key：

- 单行展示；
- 超长内容使用省略号；
- 鼠标悬停显示完整 Tooltip。

右侧固定“审批”列设置非透明背景，横向滚动时不会与底层字段内容重叠。

## 5. 审核候选与搜索相关性

### 5.1 审核 UI

- 批准候选：单选下拉框；
- 显式拒绝候选：多选下拉框。

不再使用纵向 Radio / Checkbox 列表占用大量空间。

### 5.2 原候选偏差根因

候选搜索原链路已经会从源影视文件名解析标题、年份、季/集信息，并据此生成站点搜索词。

问题发生在站点返回结果之后：

- 某些站点会返回宽泛搜索结果；
- 原流程会直接把返回结果进入候选评分；
- 若没有触发硬冲突，标题相关性很低的结果仍可能出现在人工审核列表。

因此“批准候选 / 拒绝候选与影视数据差异很大”并不是因为没有使用影视名搜索，而是缺少站点返回结果后的相关性门槛。

### 5.3 v1.0.14 相关性门

站点搜索结果在进入候选评分与审核前新增保守相关性过滤：

- 若源媒体与候选具有完全相同的外部媒体 ID，直接视为相关；
- 否则要求源标题与候选标题/别名之间达到最低 token Dice 相似度；
- 明显无关的站点搜索噪声不会再进入人工审核候选。

该相关性门只负责剔除搜索噪声，不替代 torrent piece 验证、执行计划校验或高风险授权。
