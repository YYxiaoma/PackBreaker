# PackBreaker v1.0.2 研发记录：八站可配置与表单简化

本变更在独立研发分支进行，不修改已发布 v1.0.1 Tag、正式 GHCR 镜像或现有生产容器。

- 添加站点可选择 HDHome、KeepFrds、UBits、HDFans、Rousi Pro、BTSCHOOL、PTTime、聆音Club，允许保存各自所需的加密凭据与只读连接测试。
- 添加/编辑表单移除「站点地址」输入框。地址来自后端固定 HTTPS SiteProfileRegistry，前端不再提供可编辑 URL；API 的额外 URL 字段不能改变后端固定同源地址。
- 八站复用 PENDING_REAL_VALIDATION 状态：允许创建、修改、独立/保存后只读测试，但新增时默认停用，前端不展示启用选项，后端正式执行白名单仍只有 M-TEAM、HDTime、HHClub。即使有人直接导入 enabled=1 的候选数据，也不能进入正式任务适配器。
- Rousi Pro 的 API Key 和独立下载 Cookie 继续分别加密；连接测试成功不能代替尚未完成的独立详情或真实下载器验收。八站未完成真实辅种任务验收，其生产执行权限仍受阻。
- 新增 MockTransport 合成认证、固定来源、凭据脱敏和任务门禁回归；不调用真实 PT 站点、Tracker 或下载器，不读取真实验收凭据。

本变更尚未包含在已发布的 v1.0.1 镜像中；要在网页看到效果，需另行完成新版本 CI、构建及部署。
