## 2. 本版本核心变化

1. 当前 11 个内置站点解除历史 `PENDING_ADAPTER` / `PENDING_REAL_VALIDATION` 运行时门禁，可按实际凭据和连接状态参与正式任务；真实鉴权、网络、站点不可用和内容错误仍失败关闭。
2. 正式接入 easychen/CookieCloud，支持 SecretStore 密码保存、本地解密、连接测试、立即同步、自动同步和域名边界匹配；Rousi Pro 只更新独立下载 Cookie，不覆盖 API Key。
3. 下载器来源不再强制位于 `/data`，可直接授权 `/downloads`、`/downloads2`、`/mnt/media` 等容器内显式挂载根；容器根、未映射绝对路径、路径穿越和符号链接逃逸继续失败关闭。

## 5. 下版升级基线

发布后 `release-baseline.json` 固定本次 v1.0.5 Tag、源码提交、数据库 revision、成功 Release run 与不可变双架构 OCI digest。后续 v1.0.6 或其它候选版本必须以 v1.0.5 作为上一正式版本重新完成相邻升级/回滚、Web updater、恢复与双架构发布门禁；不能继续使用 v1.0.4 作为正式基线。

## 6. 仍属于现场环境的验收

官方 easychen/CookieCloud 服务实现已经作为正式 Release 强制门完成真实 HTTP 协议验收，但用户自建 CookieCloud 实例的网络、反代、TLS、具体 UUID/密码和实际 Cookie 数据仍属于用户环境现场验收。仓库提供 `scripts/check_cookiecloud_readonly.py` 做只读 GET + 本地解密验证，不要求、也不得提交真实凭据到仓库。
