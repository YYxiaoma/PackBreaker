## 功能范围与真实验收豁免

- 本版本正式启用的 PT 站点仍仅为 M-TEAM、HDTime、HHClub。KeepFrds、HDHome、UBits、HDFans、BTSCHOOL、PTTime、Rousi Pro、聆音Club 八站仅完成候选适配与有限的只读/模拟测试，仍为 `PENDING_ADAPTER`；正式 UI/API 不允许保存配置、启用站点或执行生产辅种任务。
- 项目负责人明确决定**豁免本次新增站点真实业务验收**以推进版本发布；这不等于八站已通过真实拆包辅种、下载器校验或现场回滚验收。HDFans 的真实搜索分页仍存在 `SITE_UNAVAILABLE` 未解决记录，Rousi Pro 独立详情接口亦未完成真实验收。
- 此豁免不取消已执行的源码质量门禁、双架构镜像实际运行、相邻版本升级/回滚和供应链资产验证。正式版没有主动修改生产下载器、媒体或站点凭据。

## 后续研发基线

完成发布后将 `main` 的源码同步到已发布 v1.0.1，并将 `release-baseline.json` 指向上述已发布不变摘要；此仓库后续版本须以上一正式版 `v1.0.1` 为相邻升级/回滚基线。历史 v1.0.0 镜像、Tag 与恢复工作流保留作为审计和回滚证据。

发布后 `main` 与正式 `v1.0.1` 处于相同版本号时，日常 CI 继续执行独立镜像启动、健康检查、备份/恢复与已发布基线镜像的只读运行检查；同版本**不伪装为跨版本升级**。一旦下一研发候选版本高于该基线，`scripts/ci_release_relation.py` 将重新开启 CI 的跨版本升级/回滚和 updater E2E；低于基线时立即失败。正式 Tag 发布流水线不使用该日常 CI 条件跳过机制，其发布前相邻版本门禁始终保留。
