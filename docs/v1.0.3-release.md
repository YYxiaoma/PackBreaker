## 本版能力与现场验收边界

- 修复 `user: "0:0"` 启动后按 `PUID/PGID` 降权时不必要地清空 docker.sock 所需附加组的问题；仅在 socket 类型、所属数字组和许可满足条件时保留必要组，不修改宿主机 socket 权限。
- 在线升级错误提示区分 socket 缺失、权限问题、Docker Engine 不可访问及主容器不可读取。版本弹窗删除手动「版本回退」区域，但升级前备份、风险确认、升级失败自动回滚仍保留。
- 隔离 Docker E2E 已证明上述 `PUID=1026`、`PGID=100`、`no-new-privileges` 组合下的连接能力，不代表用户 NAS 的 socket 模式、Docker API 策略或用户实际容器已完成现场验收。旧 v1.0.1/v1.0.2 的在线升级若被旧入口的降权缺陷阻断，需要在用户自行备份后由宿主机手动更新一次，不能要求旧版自动获得修复。
- 八个新增站点仍为 `PENDING_REAL_VALIDATION`，只允许加密保存配置与只读连接测试，后端继续禁止正式辅种任务；本次正式发布没有完成它们的真实任务验收。

## 下版升级基线

发布后 `release-baseline.json` 固定本次 `v1.0.3` Tag、原始源码提交、不可变 OCI Index、数据库 revision 和成功恢复 run `35991628455`。后续高版本候选必须重新完成相邻版本升级、回滚及 updater E2E；同版本日常 CI 不得把自身升级作为跨版本验收成功。
