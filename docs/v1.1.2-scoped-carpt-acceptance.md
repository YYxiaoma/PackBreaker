# v1.1.2 CarPT 受限真实验收模式（第一阶段：只读执行）

> 本功能是**按单个手动任务授予短期站点只读验收权限**，不是把 CarPT 从 `PENDING_REAL_VALIDATION` 改为正式 `SUPPORTED`。第一阶段仅允许任务启动、站点匹配、torrent 获取与媒体内容只读验证，**绝不允许文件物化、辅助文件下载或外部下载器 ADD/RECHECK/START 写入**。七站真实完整 E2E 依然未通过，正式发布继续阻断。

## 现有隔离任务

- 原实例：`runtime/v111-cookiecloud-review`（带既有 CookieCloud、CarPT Cookie、Transmission 与 qB）
- 已存任务：`f432f681-8d36-4927-b79e-b0e10fbaa535`，手动、指定 1 部影片、来源为《九品芝麻官》原目录、扫描站点仅 CarPT、目标下载器仅 Transmission
- 输出：`/workspace/PackBreaker/runtime/data/downloads2/packbreaker-v112-isolated-acceptance`
- 存储方式：`COPY`（独立 inode）；冲突策略：`VERIFY_REUSE_OR_STOP`；自动重试：关闭
- 站点 CarPT 仍未启用为全局站点，`SiteService.enabled_adapters()` 对普通任务不可见。已有其他站点和其他任务不会由此获得权限。

## 权限文件及只读冻结

仅在管理员明确授权后，由受控本地操作在实例 config 目录写入：

`v112-unpack-readonly-acceptance.json`

文件必须是 `0600` 的非符号链接普通文件（不超过 4 KiB），包含 **恰好**九个字段：

```json
{
  "schema": "packbreaker-v112-readonly-site-acceptance-v1",
  "definition_id": "f432f681-8d36-4927-b79e-b0e10fbaa535",
  "site_id": "<existing CarPT site UUID>",
  "site_version": 1,
  "downloader_id": "<existing Transmission downloader UUID>",
  "source_directory": "<approved exact original source directory>",
  "source_filename": "<exact selected .mkv basename>",
  "output_directory": "/workspace/PackBreaker/runtime/data/downloads2/packbreaker-v112-isolated-acceptance",
  "expires_at_utc": "<short UTC ISO-8601 expiry, within 72 hours>"
}
```

站点必须是具有原有有效凭据、连接 `OK` 且未在正式 Registry 开放的 `CARPT`；目标下载器必须是已启用且连接 `OK` 的 `TRANSMISSION`。校验任务 ID、站点 ID/版本、下载器 ID、来源目录、**单个**选中视频及严格输出路径；源/目标/执行模式或版本有任意变化、文件过期/缺失/权限不符都拒绝匹配。不能借用其他站点、任务、影片或下载器。

验收任务启动后在 `execution.config_snapshot.acceptance_mode` 写入 `READ_ONLY_SITE_ACCEPTANCE` 冻结标记，随后即使撤销权限文件、修改任务或禁用站点，物化、辅助文件 staging、外部种子 ADD/RECHECK/START 均继续禁止。读阶段只会为该精确 execution 提供 CarPT 适配器，**不更改生产全局 Enabled Adapters 或 Registry 状态**。

## 下一阶段仍需独立实现和验收

这一阶段优先解决“未通过验收不能启用、不能启用又无法验收”的只读入口循环。它不声明真实下载器操作已获执行环境许可，也不会清除冲突或人工对账 journal。完成任务匹配及源文件内容的同一 execution 证据后，仍需要逐项开发并检验严格受控的**真实写入门禁**，取得目标目录及外部 ADD/RECHECK/START 的成功证据，才可考虑把 CarPT 记为真实完整 E2E 已验收。绝不可直接改写上述冻结标记/Registry/数据库 enabled 字段来绕开限制。

完整候选 CI 和发布镜像摘要的历史记录见 `docs/v1.1.2-development.md`。
