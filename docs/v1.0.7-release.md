## 2. 本版本核心变化

1. 任务中心新增“影片去重”，A 目录作为保留源、B 目录作为去重目标，不新增独立左侧导航。
2. 候选采用文件大小、影片元数据与快速指纹分层筛选，自动替换前必须完整 SHA-256 一致；内容相同但元数据不足时进入人工确认。
3. 同一文件系统默认优先硬链接；跨文件系统默认阻断，不会静默退化为复制，用户明确允许时可改用软链接。
4. 硬链接替换使用 operation journal、稳定文件快照、临时硬链接与原子 exchange，并覆盖崩溃恢复。
5. 扫描、匹配、完整内容校验与 journal 恢复由后台 driver 推进，浏览器刷新或关闭不会停止任务。
6. 候选详情展示 device、inode、link count、mtime、SHA-256 与影片元数据，并区分逻辑重复大小和预计可释放空间。
7. v1.0.6 在线升级连续性继续强化：页面刷新后依据后端 helper 持久状态恢复进度关联，并避免成功后的重复 reload。
